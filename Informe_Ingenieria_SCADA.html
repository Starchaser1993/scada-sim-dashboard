2. Ingeniería de Detalle y Diagrama P&ID (Norma ANSI/ISA-5.1)

2.1. Descripción Unívoca del Proceso Industrial

La planta simulada consiste en un lazo de recirculación y acondicionamiento hidráulico-térmico integrado por tres componentes primarios:

  1. Depósito de Almacenamiento Principal (Tanque T-101): Estanque vertical de 2.500 litros de capacidad nominal dotado de transmisor de nivel continuo (LT-101), sujeto a un consumo de salida continuo de proceso.
  2. Unidad de Bombeo Centrífugo (Bomba Hydro-A): Actuador motriz impulsado mediante un variador de frecuencia (VFD-01) que modula el caudal volumétrico recirculado (0 a 75 L/min) en función de la consigna de potencia (0 a 100%).
  3. Reactor Térmico de Mezcla (Reactor R-20): Recipiente de intercambio donde el fluido recibe energía mecánica y térmica, monitorizado en tiempo real por un transmisor de temperatura (TT-101) con enclavamiento por alarma de alta temperatura (TAH-101 a 80°C).

3. Memorias de Cálculo y Modelo Matemático Dinámico

3.1. Dinámica Hidráulica y Balance de Masa (Tanque T-101)

El balance de materia no estacionario para el volumen de líquido contenido en el estanque se formula de acuerdo a la ecuación de continuidad: 

   dV(t) / dt = Q_in(t) - Q_out(t)

Expresando el volumen en términos de porcentaje de nivel relativo $L(t) \in [0, 100]\%$, el modelo discretizado por diferencias finitas con paso temporal $\Delta t = 1,0 ext{ s}$ se define como: 

   L(t + Delta_t) = L(t) + [ Q_in(t) - Q_out(t) ] * Delta_t

Donde los flujos normalizados son calculados de la siguiente forma:

  • Caudal de salida continuo ($Q_{out}$): Modela la fuga / demanda constante de proceso:
    Q_out = 1,0 %/s  (si L(t) > 0; de lo contrario 0)
  • Caudal de entrada impulsado ($Q_{in}$): Depende directamente del estado y potencia del variador de frecuencia ($P(t) \in [0, 100]\%$):
    Q_in(t) = (P(t) / 50,0) * 1,0 %/s  (si Bomba = ON; de lo contrario 0)

Comportamiento Cuantificable y Puntos Notables:

  1. $P(t) = 0\%$ (o Bomba Desconectada): $Q_{in} = 0,0\%/ ext{s} \implies \Delta L = -1,0\%/ ext{s}$. El estanque experimenta una pendiente de vaciado constante de 1% por segundo.
  2. $P(t) = 25\%$: $Q_{in} = 0,5\%/ ext{s} \implies \Delta L = -0,5\%/ ext{s}$ (vaciado amortiguado).
  3. $P(t) = 50\%$ (Punto de Equilibrio Hidrostático en Régimen Permanente):
    Q_in = (50 / 50) * 1,0 = 1,0 %/s ===> Delta L = 1,0 - 1,0 = 0,0 %/s
    En esta condición, el nivel se mantiene estrictamente invariante en el tiempo ($dL/dt = 0$).
  4. $P(t) = 75\%$ (Consigna del Lazo Autónomo PLC): $Q_{in} = 1,5\%/ ext{s} \implies \Delta L = +0,5\%/ ext{s}$. Llenado sostenido hacia la cota máxima permitida.
  5. $P(t) = 100\%$: $Q_{in} = 2,0\%/ ext{s} \implies \Delta L = +1,0\%/ ext{s}$. Tasa máxima admisible de carga.

3.2. Dinámica Térmica y Disipación Energética (Reactor R-20)

La temperatura del fluido en el reactor evoluciona de acuerdo a la Ley de Enfriamiento de Newton acoplada a la generación de calor por fricción hidrodinámica del impulsor: 

   dT(t) / dt = k * [ T_target(P) - T(t) ]

Donde la temperatura asintótica de equilibrio $T_{target}$ se calcula a partir de la temperatura ambiente base ($T_{amb} = 22,0^\circ ext{C}$) y la potencia inyectada: 

   T_target = T_amb + (P(t) / 100,0) * 68,0 °C  [Rango asintótico: 22°C a 90°C]

La tasa de variación instantánea $\Delta T$ en cada ciclo de 1 segundo se calcula según el gradiente térmico:

  • Régimen de Calentamiento ($T(t) < T_{target}$):
    Delta_T_heat = min(1.2, max(0.25, (T_target - T) * 0.035)) + Ruido(±0.07°C)
  • Régimen de Enfriamiento Rápido ($T(t) > T_{target}$ o Bomba OFF):
    Delta_T_cool = -min(2.0, max(0.7, |T_target - T| * 0.07)) + Ruido(±0.07°C)
Criterio de Seguridad Térmica (Alarma Crítica TAH-101): Si la temperatura de proceso supera los 80,0 °C, el sistema activa automáticamente un indicador estroboscópico de alerta, emite una entrada prioritaria en el registro de auditoría (tipo DANGER) y solicita la intervención inmediata del operador o la activación del E-STOP.

                                      v

                          |  (Bomba en reposo 0%)  |

4.2. Algoritmo de Control en Lazo Cerrado por Histéresis (PLC Autónomo)

Cuando el sistema se conmuta a Modo Automático, el PLC asume el gobierno autónomo de la bomba para mantener el nivel del tanque dentro de una banda de tolerancia óptima, evitando ciclamientos excesivos del motor: 

   SI Modo == "AUTO":
       SI Nivel_Tanque <= 30.0% Y Bomba == OFF:
           Bomba = ON
           Potencia_VFD = 75%
           Registrar_Log("PLC Modo Auto: Encendido por nivel bajo <= 30% a 75% potencia")
       
       SINO SI Nivel_Tanque >= 88.0% Y Bomba == ON:
           Bomba = OFF
           Potencia_VFD = 0%
           Registrar_Log("PLC Modo Auto: Apagado de seguridad por nivel alto >= 88%")

4.3. Protocolo de Parada de Emergencia (E-STOP según IEC 60204-1)

En cumplimiento con el estándar internacional de seguridad en maquinaria IEC 60204-1 (Categoría de Parada 0/1):

  • Corte Inmediato: Desconexión instantánea de la bomba y reducción de la potencia del VFD a 0%.
  • Despresurización: Caída progresiva de presión en la línea de descarga hasta 0 PSI.
  • Enfriamiento Forzado: Reducción inmediata de la temperatura del reactor hacia el estado pasivo.
  • Enclavamiento de Seguridad: Todos los controles manuales de velocidad y encendido se inhabilitan en la interfaz hasta que un operador calificado ejecute el procedimiento formal de Rearme del Sistema.

5.2. Almacenamiento Criptográfico Seguro de Credenciales

Para impedir la exposición de credenciales en texto claro dentro del código fuente o la memoria del navegador, se integró el motor criptográfico nativo del estándar W3C window.crypto.subtle con algoritmo SHA-256: 

   const hashPassword = async (text: string): Promise<string> => {
     const msgUint8 = new TextEncoder().encode(text);
     const hashBuffer = await crypto.subtle.digest('SHA-256', msgUint8);
     return Array.from(new Uint8Array(hashBuffer))
       .map((b) => b.toString(16).padStart(2, '0'))
       .join('');
   };

5.3. Sincronización Concurrente de Sesiones Activas

A través de un canal de difusión inter-hilo (BroadcastChannel('scada_presence_channel')) complementado con un pulso de presencia (heartbeat) cada 2.500 ms en localStorage, la plataforma detecta en tiempo real la conexión o desconexión de operadores desde distintas ventanas o puestos de trabajo, caducando automáticamente sesiones inactivas tras 8 segundos de inactividad.

6. Manual de Instalación, Puesta en Marcha y Operación

6.1. Requisitos de Plataforma y Dependencias

  • Entorno de Ejecución: Node.js v18.0 o superior con npm v9.0+.
  • Framework y Lenguaje: React 19.x con TypeScript 5.x / 6.x.
  • Empaquetador y Servidor Local: Vite 8.x con Tailwind CSS v4.
  • Navegador Recomendado: Google Chrome 110+, Microsoft Edge 110+, Mozilla Firefox 115+.

6.2. Procedimiento de Puesta en Marcha Local

  1. Acceder al directorio del proyecto: 
    cd /root/dev-ia/proyectos/scada-sim-dashboard
  2. Instalar dependencias declaradas en package.json: 
    npm install
  3. Iniciar el servidor de desarrollo con recarga en caliente (HMR): 
    npm run dev
  4. Compilar el paquete estático optimizado para despliegue en servidor web HTTPS (*.org): 
    npm run build
    Los binarios resultantes se generan en el directorio dist/ listos para producción.

6.3. Guía de Operación Paso a Paso

  1. Acceso al Sistema: Iniciar sesión en el portal seleccionando una cuenta autorizada (ej. operador1) o ingresando las credenciales correspondientes.
  2. Verificación de Parámetros: Comprobar en el panel superior que el estado general indique SISTEMA ONLINE y el reloj se encuentre sincronizado.
  3. Maniobra de Llenado Manual:
    • Presionar el botón "ENCENDER BOMBA". El indicador LED cambiará de rojo a verde brillante.
    • Deslizar el potenciómetro VFD a 75% o utilizar los botones de acceso rápido.
    • Observar en el diagrama P&ID la circulación dinámica de fluido y el incremento paulatino de nivel en el Tanque T-101 (+0,5%/s).
  4. Prueba del Lazo Autónomo (Modo AUTO):
    • Pulsar la pestaña "Automático". El sistema desplegará el distintivo verde CONTROL AUTÓNOMO ACTIVO (PLC).
    • El PLC regulará autónomamente el llenado y vaciado dentro de los umbrales seguros (30% - 88%).
  5. Maniobra de Parada de Emergencia (E-STOP):
    • Presionar el botón rojo "E-STOP". Se generará una alarma sonora y visual en el reactor.
    • La bomba se desenergizará de inmediato. Para reanudar el control, pulsar "Rearmar Sistema (Reset E-STOP)".
